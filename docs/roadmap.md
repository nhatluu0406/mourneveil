# Roadmap

- Repository governance
- Local Vite/React/TypeScript scaffold
- Three.js / React Three Fiber / Rapier wiring
- Strict TypeScript
- Test harness
- Minimal CI
- Foundation runtime proof
- No gameplay systems

- Character movement

- Debug overlay

- Dodge
