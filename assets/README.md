# Production assets

- Editable sources live under `assets/source/`; runtime code never reads this directory.
- Imported runtime assets live under `public/assets/` and are committed with their source and manifest entry.
- `npm run assets:import` validates sources and copies them to canonical runtime paths.
- `npm run assets:verify` rejects missing/malformed assets, source/runtime drift, unsafe URLs, missing provenance/license data, invalid animation semantics, and budget violations. `npm run build` runs it first.
- M8 supports embedded `.gltf` and preferred production `.glb`, meters, Y-up, ground-centered pivots, `none-external`/`embedded-only` textures, and explicit authored physics proxies. Render meshes never author collision.
- Initial budgets: 256 KiB default per asset (entries may set tighter `maxBytes`), 1 MiB total runtime assets. No Draco/Meshopt/KTX2 unless later evidence requires it.

`world.checkpoint.refuge-shrine` is original project-authored static glTF. `enemy.skirmisher.proof` is an original project-authored skinned animated GLB generated by `scripts/assets/author-skirmisher-proof-glb.mjs`. Both contain no third-party content; redistribution remains controlled by the repository owner.
